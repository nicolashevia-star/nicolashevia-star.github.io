Política de privacidad

Última actualización: 19-11-2026 Responsable: Nicolás Hevia, persona natural en Chile. Contacto de privacidad: Asistente — asistente.nicolas.hevia@gmail.com

1. Alcance

“OpenClaw Google” es una integración de uso personal operada por Nicolás Hevia que permite al asistente ejecutar instrucciones autorizadas sobre Google Drive y Hojas de cálculo mediante las API oficiales de Google. No se ofrece como servicio general al público.

2. Datos que puede procesar

Según la tarea solicitada, la integración puede procesar:

  • Identificador y correo de la cuenta Google autorizada.
  • Nombres, enlaces, metadatos, permisos y contenido de archivos de Drive y hojas de cálculo accesibles por esa cuenta.
  • Instrucciones, resultados y fragmentos de archivos necesarios para completar una solicitud.
  • Token OAuth, guardado localmente en el llavero de macOS del Mac mini.

El permiso OAuth de Drive es amplio y técnicamente puede acceder a cualquier archivo visible para la cuenta del agente. Los permisos que el propietario concedió a cada carpeta siguen limitando las acciones posibles en esa carpeta.

3. Finalidades

Los datos se usan para ejecutar las tareas que Nicolás solicita sobre sus archivos y hojas, autenticar la cuenta y mantener, proteger o diagnosticar la integración. No se venden datos ni se usan para publicidad o finalidades ajenas a esas tareas. OpenAI indica que el contenido enviado a su API no se usa para entrenar sus modelos de forma predeterminada.

4. Servicios y destinatarios

Google procesa la autenticación y las solicitudes de Drive/Sheets. OpenClaw se ejecuta en el Mac mini y conserva localmente el historial necesario para operar. El contenido relevante puede enviarse a OpenAI API para generar respuestas. OpenAI indica que los datos de API no se usan para entrenar modelos por defecto y que los logs de monitoreo de abuso pueden contener contenido y conservarse hasta 30 días, salvo excepciones legales o de seguridad: https://platform.openai.com/docs/guides/your-data. El tratamiento de datos de usuario de Google se rige por su Política de datos de usuario de los servicios de API: https://developers.google.com/terms/api-services-user-data-policy. GitHub Pages alojará únicamente las páginas legales estáticas; no recibe contenido de Drive por esta integración. GitHub puede recopilar la dirección IP, datos del dispositivo y detalles de sesión de quienes visitan el sitio, según su política de privacidad: https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement.

5. Conservación y seguridad

El token OAuth se guarda en el llavero de macOS y puede revocarse desde la cuenta Google. OpenClaw conserva sesiones y transcripciones localmente; con la configuración actual sin una regla de mantenimiento personalizada, el valor predeterminado archiva conversaciones elegibles después de 30 días de inactividad. Archivar no las borra: los archivos pueden conservarse hasta eliminación manual o limpieza por límite de almacenamiento. No se promete una fecha fija de borrado total. Se aplican controles de acceso del sistema operativo y de Google; no se promete seguridad absoluta. Para el tratamiento de OpenAI API rige su retención de logs de abuso descrita arriba.

6. Opciones del usuario

Nicolás puede dejar de usar la integración y revocar su acceso desde https://myaccount.google.com/permissions. Para solicitar acceso, corrección o eliminación de datos locales, contactar a Asistente en asistente.nicolas.hevia@gmail.com. La revocación impide futuras llamadas autorizadas, pero no elimina automáticamente copias, archivos originales, transcripciones archivadas ni registros que Google u OpenAI deban conservar.

7. Cambios y contacto

Los cambios materiales se publicarán en https://nicolashevia-star.github.io/privacy.html. Responsable: Nicolás Hevia, persona natural en Chile. Contacto: Asistente — asistente.nicolas.hevia@gmail.com.
